# AR Marker Angle & Border Visualizer + WebSocket Relay

Автономний модуль WebAR та сервер ретрансляції для:
- візуалізації зеленої рамки навколо маркерів:
  - BarCode-маркерів (матриця 3x3);
  - ArUco-маркерів (словник 4x4_1000), генерація зображень - https://tagsgen.top/
- визначення кута нахилу відносно горизонту та передачі значення `"angle_x"` через WebSocket у Scratch чи інші застосунки.

## Можливості
- **Вибір вебкамери:** підтримка декількох камер через аргумент командного рядка (`--camera=0`, `--camera=1`) або випадаючий список у веб-інтерфейсі.
- **Зелена контурна рамка:** апаратно рендериться на GPU навколо периметра кожного виявленого маркера (Zero-Lag).
- **Визначення кута нахилу:** обчислює кут нижньої сторони маркера відносно горизонтальної осі екрана в діапазоні `[-180°, +180°]` (де `0.0°` відповідає горизонтальному положенню).
- **Виведення значення кута:** 3D-плашка (Sprite billboard) у браузері або нативний 2D HUD у вікні OpenCV, орієнтовані на користувача.
- **WebSocket ретрансляція (20 Гц):** автоматично надсилає дані кута нахилу у форматі `{"accX": 0, "accY": 0, "angle_x": <кут>, "angle_y": 0, "marker_id": <id>}` на порт `8767` для передачі даних до TurboWarp Scratch-середовища розробки.
- **Автоматичний запуск однією командою:** запуск локального HTTP-сервера та WebSocket-сервера ретрансляції даних про маркери:
  - `python barcode_marker_angle_visualizer_web.py` — для роботи з BarCode-маркерами через браузер;
  - `python aruco_marker_angle_visualizer_web.py` — для роботи з ArUco-маркерами через браузер;
  - `python aruco_marker_angle_visualizer_desktop.py` — для роботи з ArUco-маркерами через нативний Desktop (OpenCV).

## Експериментальне програмне забезпечення
Для перевірки роботи маркерів можна використати програму, розміщену в каталозі TurboWarpApplications\4-Cat-Run-SmartPhone.sb3

Програма містить наступний сценарій гри:
- котик біжить по доріжці, на якій періодично з'являються перешкоди;
- щоб оминати перешкоди необхідно змінювати доріжку бігу котика
- для зміни доріжки треба нахиляти маркер вліво/вправо, змінюючи кут нахилу маркера відносно горизонту;
- після зміни доріжки треба повертати маркер у горизонтальне положення.
